# Guardian Desktop

Panel Flutter planeado para Windows, macOS y Linux.

Responsabilidades: onboarding, consentimiento, permisos de cámara, selección de umbrales, dispositivos, historial y mantenimiento. No debe mantener en Flutter la autoridad del bloqueo ni de los datos biométricos: esas funciones corresponden al agente nativo.

**Todavía no existe la aplicación Flutter.**
