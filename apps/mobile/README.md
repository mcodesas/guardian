# Guardian Mobile

Aplicación Flutter planeada para Android e iOS.

Responsabilidades: iniciar sesión, inscribir celular con clave no exportable (Android Keystore / iOS Secure Enclave cuando esté disponible), aprobar/rechazar solicitudes con autenticación del SO, visualizar incidentes y administrar dispositivos.

**Todavía no existe la aplicación Flutter.** Se generará con el SDK oficial y las carpetas de plataforma correspondientes en una siguiente fase. Una notificación push no será suficiente para aprobar: la decisión deberá firmarse criptográficamente.
